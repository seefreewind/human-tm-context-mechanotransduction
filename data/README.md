# Data included in this release

Only compact project-derived tables and source/sample maps needed to inspect the manuscript's locked findings are included. Original source data remain at their cited GEO/SRA repositories. No raw FASTQ/SRA, BAM, reference-genome sequence, large single-cell matrix, or temporary alignment is redistributed.

The final ATAC QC table omits its machine-local BAM-path column; sample accessions and scientific QC fields are retained. The final QC verdict remains 6/6 incomplete and the locked module result is 0/9 passing matched-null FDR control. See `../reports/phase2R3/` for the interpretation and gate.
